# STP-12938 — Fruit Merge Cafe

A responsive landing page created to promote the Fruit Merge Cafe mobile game.
The website showcases the game's features, gameplay mechanics, player reviews,
FAQ section, and download options.

## Live Demo

🔗 https://ikerom3.github.io/STP-12938/

## Features

- Responsive design (375px mobile / 1440px desktop)
- Fixed header navigation
- Mobile burger menu
- FAQ accordion (Vanilla JavaScript)
- Smooth section navigation
- Privacy Policy page
- Terms & Conditions page
- SVG sprite icons
- Optimized images
- Semantic HTML structure

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Vite
- SVG Sprite

## Pages

- Home
- Privacy Policy
- Terms & Conditions

## Installation

```bash
git clone https://github.com/ikerom3/STP-12938.git
```
